# GSU 中文工作稿术语表

更新：2026-10-22。主线：关联风险定位转化为F0遗忘更新指导。

| 英文/符号 | 中文 | 首次定义 | 精确定义及用语边界 |
|---|---|---|---|
| GSU | 关联结构引导的知识遗忘 | 摘要 | 方法家族；最终算法待云端验证冻结，不等同已完成的v8实现 |
| F0 | 原始遗忘事实集 | 问题定义 | 唯一直接遗忘损失的数据来源 |
| F1 | 关联支持事实集 | 问题定义 | 用于定位/梯度探测；不是多跳评测问题集 |
| F0-only forget supervision | 仅F0遗忘监督 | 问题定义 | 不对F1直接施加遗忘损失；不表示不访问F1标签 |
| Q_loc / Q_dev / Q_test | 定位/开发/测试查询 | 数据权限 | 最终测试不得参与探测选集、超参数选择或更新接受 |
| Q_multi | 多跳评测查询 | 问题定义 | 与F0目标有关的间接查询；覆盖切片不是全部测试 |
| R_train / R_audit | 保护池/非锚点审计集 | 数据权限 | 是否进入反馈与是否语义相关是两个独立维度 |
| R_related / R_unrelated | 关联/低关联审计层 | 实验协议 | 图结构规则标签；低关联不等于证明语义独立 |
| component j | 组件 | 方法 | 目标矩阵的LoRA A/B对；数量随架构变化 |
| tensor b | LoRA张量块 | 方向探测 | A或B单张量；子空间不跨不兼容矩阵拼接 |
| A_j / P_j / S_j | 内部一致性/路径一致性/风险分数 | 组件定位 | 代理信号，不是已证实的因果记忆定位 |
| D_j | 同模型校准先验 | 可选组件先验 | 只在同架构独立校准可用时比较，不迁移旧层号 |
| U_b / Pi_b | 共享方向基/投影 | 方向探测 | F1梯度张成的局部子空间；不是完整推理电路 |
| d0 / d | 原始提案/最终位移 | 实际位移路由 | AdamW实际参数差，不称为原始梯度 |
| FB16 | 保留概率反馈 | 反馈 | 16锚点上的实际LP修正，不称多跳测试闭环 |
| answer LP | 答案平均对数概率 | 指标 | 只在答案token上平均，与全序列选择题分数分开 |
| MCQA margin | 选择题间隔 | 指标 | 正确选项分数减最大错误选项分数 |
| MMLU | 大规模多任务语言理解基准 | 通用能力评测 | 57学科知识问答；本批仅为每科10题的5-shot覆盖子集，非完整MMLU |
| token PPL | token级困惑度 | 通用文本预测审计 | exp(全测试有效token的平均负对数似然)，仅在同tokenizer内比较变化 |
| MQuAKE-derived | MQuAKE派生遗忘评测 | 外部多跳验证 | 从原始知识链重定遗忘事实和权限的新协议，不冒称原知识编辑任务复现 |
| RWKU | 实体级知识遗忘基准 | 外部泛化 | 多层遗忘探针、邻居及utility审计；实体目标与事实级F0分开定义 |
| empirical Pareto frontier | 经验帕累托前沿 | 实验 | 有限实测配置中的非支配集合，不称全局最优 |
| pilot / confirmation | 先导/确认实验 | 云端协议 | 已见题和单seed为先导；确认需另外冻结题目与选择规则 |
