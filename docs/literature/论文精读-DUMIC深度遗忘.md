# DUMIC精读：与GSU相关的要点

合并精简：2026-10-25。来源为本地已存论文和2026-10-19笔记：Wang等，arXiv:2609.34442v1，Making LLMs Truly Forget。本文只概括原笔记，不表示本次重新核实外部版本，也不是本项目实验结果。

## 核心方法

DUMIC针对直接遗忘后仍可经支持事实恢复的问题，按Search→Select→Sever处理：

1. 从目标主体搜索到目标答案的支持路径；结合显式回答与J-Lens隐式实体发现，逐边验证关系，并受最大深度/候选预算约束。
2. 判断路径是否真正支撑目标；收集子图，用MCQA和温度校准验证模型掌握，路径置信度取各边置信度的最小值。
3. 将边置信度作为遗忘代价，求命中已发现路径的最小割；割集连同目标输入既有遗忘算子，而非无差别遗忘完整子图。

“最小”只针对已发现子图及其权重，不保证所有潜在恢复路径消失。非零目标概率下降与路径被切断是不同观察，图构建错误、置信校准、路径漏检和judge偏差均影响结论。

## 原笔记记录的实验范围

Harry Potter参考图、100个目标，Qwen3.5-27B与Gemma4-31B；GA/NPO/SimNPO及GDR组合，比较直接遗忘、全支持子图与最小割设置，另有LoRA实验。原指标包括路径下降UES、邻域一致性Loc、MMLU与BBH；不与当前FaithUn全89宏回忆直接横比。原表的具体数字、超参数、温度和搜索消融完整保存在[合并前笔记](../archive/markdown_before_content_merge_20261025.zip)及[本地PDF](../2609.34442v1.pdf)。

## 对本项目的直接影响

| DUMIC关注点 | GSU需要回答的不同问题 |
|---|---|
| 选择哪些支持事实直接遗忘 | 能否把关联信息转成F0遗忘更新指导，而不是增加直接遗忘标签 |
| 最小割与全子图/浅层比较 | 最小割、贪心和随机同预算选集可作范围对照；适配最小割不等于完整DUMIC复现 |
| 路径置信度及能力代价 | 在固定口径下审计目标LP、多跳、低关联保持和能力，不能只报一个封堵率 |
| 构图与推断验证成本 | 计入定位/校准/生成开销，不把外部judge或隐式探测当免费信息 |

原笔记中的“共享公共支持知识可能造成代价”等机制解释只是待测假设，不以跨论文类似现象证明本项目因果。GA-GDR、NPO-GDR在此是文献方法名称，不表示本项目已经实现或承诺其官方复现。

可借鉴：最小割选集对照、校准后的路径审计、小型固定压力测试。执行优先级和数据权限只在[统一研究方案](../plans/GSU最终候选与帕累托验证设计.md)维护，不在文献笔记重复列待办。
