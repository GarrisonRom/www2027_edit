# GSU 方法版本记录

## M3（历史基线，保持不变）

- 更新方向：对每个可训练参数张量，将遗忘梯度沿该张量的 retain 锚点梯度方向投影出去，强度 alpha=1。
- 优化器：AdamW，lr=5e-5；LoRA r=8、alpha=16；每步抽取 4 个 retain 锚点。
- 限制：该梯度空间投影不等价于 AdamW 的参数位移投影，故不构成实际更新无害的保证。

## M3C（条件梯度投影候选）

沿用 M3 的逐参数张量投影公式和训练预算，仅当单个张量内遗忘梯度与锚点梯度的内积为正（原始梯度下降会降低锚点目标的一阶估计）时投影；非冲突张量保持原遗忘梯度。每轮记录触发投影数/检查数。

## M3U（AdamW 实际位移投影候选）

将原始遗忘梯度交给 AdamW，保存更新前参数并执行一次 AdamW；用更新后的实际参数差 `delta`（包含 AdamW weight decay 及其自适应状态影响）计算采样锚点聚合梯度 `g_r` 与 `delta` 的全局内积。若 `g_r · delta < 0` 且 `||g_r||^2 > 1e-12`，对实际位移执行 `delta <- delta - (g_r · delta / ||g_r||^2) g_r`，并记录修正步数。

M3U 的状态检查针对每步抽到的锚点梯度聚合值，是局部一阶诊断；有限精度下的参数写回、未采样样本、非线性高阶项和多步累计变化都可能令真实答案概率下降。AdamW 内部动量仍按未修正遗忘梯度更新，因此后续每步继续重新检查实际位移。M3C/M3U 为待验证候选，不代表已优于 M3。

## 评测与复现

候选比较由 [`exp002 GSU 更新投影实验卡`](../../exp/runs/exp002_gsu_update_projection/card.md) 冻结。原始 M3 的 adapter、指标和旧 JSONL 不覆盖；新候选采用独立 adapter 名称和 `gsu_projection` 结果前缀。结果 claim 更新前必须完成子集诊断，并遵守单 seed 证据边界。
