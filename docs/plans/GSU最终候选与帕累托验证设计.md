# GSU研究与验证方案

2026-10-25内容合并版。统一原大纲、候选设计、RQ计划、假设矩阵和数据筛选；不改既有实验卡，不自动启动新实验。最终GSU尚未确认，本文件不维护实时进度或复制成绩表。

## 研究问题与数据权限

主线：从关联知识定位多跳回忆风险，将其转为遗忘更新指导，检验仅以F0构造遗忘损失时能否更有效抑制关联多跳回忆，而非仅造成整体退化。

- F0：FaithUn官方forget的33条直接事实；F1：历史选出的5条关联支持事实，不等同多跳评测查询。
- F0-only指遗忘损失来源，不表示只访问F0。F1标签/梯度、路径与retain反馈的额外信息及计算必须披露。
- retain66分前33训练保护、后33审计；使用全部66训练的原生轨不能称后33为heldout。索引互斥不证明实体、答案或路径独立。
- 定位、开发、确认题需分开。当前89条路径/267个改写题及覆盖25路径/75题已参与探索，不能改名为未见确认集；最终测试不能参与选集、护栏、超参或检查点选择。
- “知识无法经任何方式恢复”超出有限MCQA证据；低回忆也可能来自选项排序改变或通用退化。

## 方法合同

| 环节 | C1/C2共同部分 | C2增加项 |
|---|---|---|
| 关联定位 | 基于F0内部梯度一致性、F0/F1对齐和路径覆盖计算组件分数S；w=(1+S/maxS)/2，零分退回全1 | 同左 |
| 原始更新 | 仅F0答案平均logprob产生一次AdamW实际位移d0，包含动量、归一化及weight decay | 同左 |
| 路由 | C1按组件令v=w*d0 | v=w*(0.5*d0+0.5*P*d0) |
| 方向空间 | 不使用 | 更新1/39/77前，由5条F1梯度构造每个LoRA张量的正交基U，P=UU^T，rank≤5，相对阈值1e-6；零梯度identity fallback |
| 反馈 | 每步16个retain锚点，最多2轮实际logprob反馈；路由和反馈共用0.30*norm(d0)修正半径 | 同左 |
| F0护栏 | 若d0使当前F0样本logprob下降r>0，最终下降至少0.9r，容差1e-6；按1/.5/.25/0回退，0恢复原提议，不再推进优化器 | 同左 |

护栏只保证该次有下降的F0提议的局部进展，可能撤销保护；不保证累计retain、整套F0或F1下降。F1及多跳题不参与接受条件。方向过滤不是新增负F1梯度，也不自动保证关联查询变化的符号。非零梯度列缩放不改变完整子空间，不能额外宣传为方向加权。

当前实现：[本地对齐worker](../../exp/train/run_local_gsu_c_group.py)、[实际位移操作](../../exp/train/run_cloud_gsu_c2.py)。具体环境、seed、训练步数、LoRA模块、checkpointing及来源哈希以每张实验卡/冻结快照为准，不能因本文件整理而变更。

历史B型分数叠加旧G1/G2 FFN损伤先验，不继承A组训练权重；旧层号与先验不能直接迁移到新模型。初始化LoRA-A梯度为零需单独处理。固定梯度缩放可能被Adam归一化抵消，是待诊断解释，不是已证唯一原因。

## 必要比较与待补项

| 类别 | 比较 | 回答的问题 |
|---|---|---|
| 文献方法 | GA、GradDiff、NPO、SimNPO、RMU、DPOmis、DPOrej、CEU、PDU、WGA、SatImp、UNDIAL；KLUE单独原生轨 | 是否超过合理复现和调参的强对手；配方差异见统一审计 |
| 扩展监督 | GA-F0+F1及开发集冻结的强baseline-F0+F1 | F0损失指导能否替代直接遗忘支持事实，不隐藏额外监督参照 |
| 范围对照 | G1=F0，G2=贪心扩展，G3=全候选，G4=同规模随机，G5=仅支持事实 | 筛选是否优于只增加数据和随机扩展；本地有历史结果，8B不能假定已有 |
| 无指导消融 | C0=原有反馈；Cg=无路由/方向但有护栏；C4=方向+护栏 | 改善来自关联指导、护栏还是一般反馈 |
| 匹配随机 | C1随机组件；C2R随机分数映射；C2D同张量等秩随机方向 | 结构信号是否必要，匹配层/模块、参数量、权重分布与修正幅度 |
| 成本与强度 | 等更新、等计算、相近F0遗忘强度，以及统一开发集调参预算 | 改善不是更多前反向、步长缩小或较弱对手造成 |

本地C3/C3R/C3D使用B型先验，C3R不是C1的匹配随机对照。CLUE为另外的定位方法，尚需来源/权限/架构审查，不能与KLUE混名或虚填结果。最小割支持事实选择是可选外部机制对照，不等于完整DUMIC复现。

## 验证矩阵

| 问题/假设 | 最小可判别实验 | 什么结果不支持解释 |
|---|---|---|
| RQ1 直接遗忘与多跳回忆分离 | Original、F0-only、F0+F1，同题逐路径与答案LP交叉审计 | 只换选项排序，或底模本来不会答 |
| RQ2 指导改善遗忘—影响权衡 | 同模型、同F0强度下比较多跳、低关联影响、能力与成本 | 收益可完全由GA强度/整体退化解释 |
| RQ3 组件与方向有特异性 | 真实评分对随机评分；真实方向对等秩随机方向；Cg/C4 | 随机或统一缩放解释全部收益 |
| RQ4 更新兑现定位 | raw/路由/反馈/final位移诊断；选中组件撤销、仅保留及匹配随机撤销 | 分数不对应实际位移，或反馈经常被护栏撤销 |
| RQ5 稳定与迁移 | seed42/43/44；固定F1对模型重探测F1；冻结方向对三次刷新 | 单seed/单切片现象、来源共享导致假泛化 |
| H12/H13 关联保持代价 | 看输出前按三元组、实体、路径、完整答案分层并匹配初始难度 | 无观测重合组同样严重受损；不能把所有retain下降都称必要代价 |
| H14/H15 规模与共享路径 | 同架构共同题/F1，按掌握、路径密度、桥接实体及hop分层 | 两模型同时换架构/题集；3B总体多跳不升或贪心不优随机 |
| H16 F1监督替代 | 真实指导、无指导、扩展监督在独立确认集比较 | 只有破坏F1或覆盖75题优势，不能宣称保留支持事实时独立切断推理 |

历史H14数据仅是混合证据：1.5B/3B直接及改写较强不等于整体hop2更强；历史G2与随机G4在3B上持平。A/B的LP与margin变化未充分证明绝对概率抑制。原数值保留在原run和合并前归档，不在每份计划再复制一张表。

## 数据与外部验证

| 资源 | 用途与权限 |
|---|---|
| FaithUn | 当前主实验；官方split forget33/retain66/test464，其余不自动使用；保持原JSON顺序、来源哈希和许可 |
| MQuAKE-CF-3k-v2 | 优先外部路径验证。F0取原始target_true及原始链，不用target_new/new_answer；questions只评测，不能训练；按主体/共享边连通组隔离并核对与FaithUn重叠 |
| RWKU | 实体级第二基准候选。target、训练材料和level1/2/3测试探针权限分开；neighbor不自动视为无关；记录revision、CC-BY-4.0许可与字段，不把测试探针抽成训练再称原协议 |
| Mirage/llm2graph | 相关工作及可选压力测试/工具，不是GA同类训练baseline；不必先重建图，不上传给外部API；若运行冻结生成器、提示、成本、质检和攻击预算 |
| MMLU/WikiText2 | 统一能力审计；精确定义仅维护在指标说明，不替代多跳主指标 |

MQuAKE本为编辑基准，本项目只能称derived unlearning evaluation；原单跳、三元组、别名及case边界需实际字段审计，无现成错误选项不得编造FaithUn式MCQA。RWKU配置字段不保证一致，先做小规模加载/底模掌握审计，不自动跑全部目标。新增数据须另卡，不能混入已冻结FaithUn批次。

## 统计与报告规则

- 所有方法共享开发集和搜索预算；历史建议lr网格2.5e-5/5e-5/1e-4不是已执行最优搜索，额外beta/retain权重也要等额登记。F0终点和检查点规则先冻结，不按测试最优选38/76/114步。
- 三seed保留逐seed结果、均值/样本标准差和n；Original一次不复制为三次。按源主体/连通组整簇bootstrap，不将267个相关改写当独立样本；校正多比较，不能用CI是否重叠替代配对检验。
- 主经验前沿为全89路径回忆↓与独立utility↑，同时标F0可行性；MMLU/PPL和成本分别审计。F0-only与扩展监督、原生与LoRA分别报告，跨模型不合前沿。
- 一个配置只是点；不同算法不平滑连线。同方法仅连接实测强度，经验非支配不等于全局最优，也不自动等于有效遗忘。
- 定位干预匹配预算，记录预测与实际LP；局部推导不证明真实记忆电路或所有恢复路径消失。
