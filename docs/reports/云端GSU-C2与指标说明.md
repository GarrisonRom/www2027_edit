# 遗忘实验指标说明

2026-10-25合并精简版。本页只解释指标、方向和读表规则；不再复制主表、C组排名或过期运行状态。方法流程见[研究方案](../plans/GSU最终候选与帕累托验证设计.md)，配方见[baseline审计](../audits/本地baseline复现审计_20261024.md)。

## 数据名称

F0是要求遗忘的直接事实；F1是关联支持事实，F1直接题不等于F1覆盖多跳题。FaithUn当前forget33、retain66、test464；全hop2为89条路径、267个改写题，其中历史F1覆盖25路径/75题，未覆盖64路径/192题。覆盖切片并不是全部多跳，更不是未见测试。

## 指标与方向

| 指标 | 含义 | 优化方向/边界 |
|---|---|---|
| F0直接、改写正确率 | 目标事实在原问和改写上的残留回忆 | ↓；原问下降不代表改写或多跳也下降 |
| 全89路径宏回忆 | 每条路径先平均其改写，再平均89路径 | ↓；当前主指标。每条恰3改写时等于267题微均值，不产生额外独立样本 |
| 覆盖/非覆盖多跳 | 对指定支持事实覆盖与其余路径分别审计 | ↓；不能只挑75题证明总体收益 |
| F1直接事实 | 支持事实本身的可访问性 | 审计，无统一优劣；扩展监督可期望↓，F0-only指导不能自动把破坏F1当优势 |
| 训练retain、审计retain | 参与保护的知识与未参与保护的知识正确率 | ↑；独立性看实际训练池，原生轨若用了66条则后33不是heldout |
| same_object、D/K历史切片 | 同答案或旧损伤/恢复研究的分组表现 | 按任务解释；D_hop2有F1重叠项，不能一面要求遗忘一面当必须保持 |
| answer LP | 答案token平均log概率（nats） | 遗忘集↓；保持集↑。越负表示该答案几何平均token概率越小，不等于选择题结果 |
| MCQA margin | 正确选项分数减最强错误选项 | 遗忘集↓、保持集↑；<0表示错误项得分更高；历史全串分数与答案LP分开命名 |
| ΔLP | 当前答案LP减Original | 遗忘集期望负；保持审计看负向损伤与漂移，不能把其“越接近0”和绝对能力↑混成同一排名 |
| MMLU-10/科目 | 57科各固定10题、5-shot，共570题的正确率 | ↑；多学科选择题审计，不是完整MMLU或全部推理能力 |
| MMLU Δpp | 准确率相对同模型Original的百分点变化 | ↑；例如.70→.68是−2pp，不是−2%的相对变化 |
| WikiText2 token PPL | exp(总NLL/有效目标token数) | ↓；一般文章预测，不是数据集名、错误率或百分比 |
| PPL比值、ΔNLL | PPL/PPL_original、meanNLL−meanNLL_original | ↓；比值1/ΔNLL0是无变化，绝对PPL不跨tokenizer排高低 |
| 时间/峰值显存/可训练参数 | 计算与资源代价 | ↓代表更省，不单独代表算法好；加载、定位、训练、反馈、评测需标计时范围 |

同题选择题下降可能只是干扰项相对排序变化，需结合目标答案LP、生成式EM/F1和独立保持审计。MMLU稳定不能掩盖PPL暴涨；PPL异常也应先查加载、掩码和计数，再解释机制。三选一随机水平约1/3，不是确定性模型的严格分数下界，也不能以低于随机证明知识消除。

## 能力评测的冻结口径

- 当前云端MMLU：固定harness版本、57科各10测试题，seed42无放回样本计划、5-shot、无chat template、batch1。训练seed42/43/44不换测试题；保存subject/sample输出、索引和任务版本。完整MMLU必须另标，不能混表。
- WikiText2 raw test：固定revision与文本哈希，官方text以双换行拼接，tokenizer允许时加一个BOS；context≤2048、stride512；每个next-token标签只计一次，报告总NLL/目标token数/meanNLL/PPL。不是逐句PPL均值。
- harness word_perplexity、byte_perplexity不是这里的token PPL。0-shot/5-shot、raw/chat、原始/过滤语料分开；不能按某方法有利的口径事后替换主项。
- 同模型Original和所有方法使用共同协议；裸MCQA历史整段均值、答案条件概率和FaithUn原文模板属于不同评分口径。AA/MA类综合分若使用，必须列公式、forget/test范围和方向，不能与“剩余多跳回忆↓”直接比数字。

## 结果和方法怎样读

Original是不训练参照；GA直接压低目标概率；GradDiff兼顾forget与retain；NPO依赖冻结参考，SimNPO不依赖；RMU干预表示；KLUE定位原生神经元。C1/C2对F0提议做关联指导，C2另加方向子空间。具体配方与适配差异统一看审计，不从方法简称推断等预算。

比较必须同时看F0、多跳、独立保持、MMLU、PPL和成本。F0-only/扩展监督、原生/LoRA、不同模型分面板；不未经预注册把所有列加成总分，不只挑utility最好的一项画“最优”前沿。三种子报告逐seed、均值/标准差及n，小差异不自动等于显著。
