# 研究证据总账

> 版本：v1　更新时间：2026-10-19
>
> 用途：把论文 claim、冻结评测、实验产物和运行档案放在同一张可审计清单中。结果文件是数字的优先来源；没有独立 run log 的历史结果不补造 run_id，而是明确记录归档缺口。

## 1. 当前主线

**Claim-v2**：在 FaithUn 的三选一 MCQA 协议下，模型前向探测能够在固定扩展预算内筛出对多跳恢复风险有用的支持事实；遗忘产生的保留知识损伤可以通过双模型显影、组件干预和留出预测进行量化；在此基础上，方向级恢复约束比单纯阻尼或答案级硬约束更能改善恢复—回弹权衡。

这句话不包含以下未被当前证据支持的强断言：跨架构普遍有效、显著优于随机、严格支配全部 baseline、已经同时满足回弹和 F1 复活硬指标。

## 2. 冻结协议与版本

| 项目 | 当前冻结值 |
|---|---|
| 数据 | FaithUn，200 个实体、664 个事实簇；原始文件与 split 保存在 `data/faithun/` |
| 主评测 | 三选一 MCQA，长度归一化续写 logprob，argmax 判定，无 chat template |
| 1.5B 主线 | Qwen2.5-1.5B-Instruct，GA-LoRA v2，r=8、alpha=16、lr=5e-5、3 epochs、KL alpha=10 |
| 3B 扩展 | Qwen2.5-3B-Instruct，clean run，seed=42；结果只作单 seed 扩展验证 |
| 内容二/三 | 1.5B G1/G2 双模型对；内容三以 G2 为恢复起点 |
| 主要方向 | 遗忘率和恢复率越低越好；retain、same_object、K 越高越好；回弹、F1 复活、K 漂移越低越好 |

## 4. 假设与否定结果

| ID | 假设或预期 | 证据结论 | 决策 |
|---|---|---|---|
| A1 | 受损题主要在中高层 | G2 分离带在层 1–4，高层存在背景漂移 | 修正为“低层指纹、高层背景” |
| A2 | 注意力头或 top-k 神经元可直接作为恢复位置 | 注意力头为 null；top-12 神经元与随机接近 | 恢复粒度改为层/模块，神经元手术不作为主路线 |
| A3 | Fisher/梯度代理可区分高损伤题 | D/K 梯度剖面几乎重合 | 保留为否定结果，补正式 Fisher 对照 |
| A4 | 增强 KL 强度可以守住 retain | G6 的 KL 约束更强但 retain 和 same_object 更差 | 判定为结构性覆盖盲区，转向目标/方向级约束 |
| A5 | 答案级硬 hinge 可以阻止遗忘回弹 | R2/R4 恢复为负或显著变差 | 不再作为主方法 |
| A6 | 3B 上 G2 应显著优于随机 | clean run 中 G2 与 G4 均为 0.236 | 不作该强断言，补多 seed |

## 5. 已作出的文档决策

1. `3B_v2_clean` 是 3B 最终数字；`3B_v1` 只保留为有警告的历史现场。
2. 1.5B 机制验证、3B 扩展验证、GSU 和恢复实验分开报告，不把不同模型或方法版本合并为一个主结果。
3. 研究内容二的贡献表述收束为“可预测的损伤显影与恢复选址器”，不宣称完整因果电路。
4. 研究内容三的当前结论是“方向级约束改善 trade-off，但硬指标部分未通过”，不把 R5 写成完整成功。
5. GSU 不写“严格支配全部 baseline”；使用 D_hop2—retain 联合目标和逐指标对照描述。
6. 组件撤销、R5 和 GSU 的原始 JSONL/JSON 保留不覆盖；后续修正数字只能新增 run 或在报告中注明修订原因。
