## 1. 当前主线

**Claim-v2**：在 FaithUn 的三选一 MCQA 协议下，模型前向探测能够在固定扩展预算内筛出对多跳恢复风险有用的支持事实；遗忘产生的保留知识损伤可以通过双模型显影、组件干预和留出预测进行量化；在此基础上，方向级恢复约束比单纯阻尼或答案级硬约束更能改善恢复—回弹权衡。

这句话不包含以下未被当前证据支持的强断言：跨架构普遍有效、显著优于随机、严格支配全部 baseline、已经同时满足回弹和 F1 复活硬指标。

## 5. 已作出的文档决策

1. `3B_v2_clean` 是 3B 最终数字；`3B_v1` 只保留为有警告的历史现场。
2. 1.5B 机制验证、3B 扩展验证、GSU 和恢复实验分开报告，不把不同模型或方法版本合并为一个主结果。
3. 研究内容二的贡献表述收束为“可预测的损伤显影与恢复选址器”，不宣称完整因果电路。
4. 研究内容三的当前结论是“方向级约束改善 trade-off，但硬指标部分未通过”，不把 R5 写成完整成功。
5. GSU 不写“严格支配全部 baseline”；旧 D_hop2 有 12/24 题与 F1 目标重叠，须拆分后再解释遗忘—保留权衡，不据旧汇总宣称“封堵满格”或联合最优。
6. exp002 的 M3C/M3U 均未通过预注册筛选门：M3C 主指标无提升；M3U 仅提升 1/12 且 retain 下降 3/33。M3A 后续验证把主指标提升到 3/12，但 retain 进一步降到 11/33；保留局部机制结果，不进入多 seed。
7. GSU 更新投影分支暂转向：聚合和逐锚点约束都改善局部锚点代理，但没有满足累计 retain 门槛。后续若继续，需另建 retain 覆盖或累计保护实验卡，不再在同一分支继续堆投影规则。
8. 组件撤销、R5 和 GSU 的原始 JSONL/JSON 保留不覆盖；后续修正数字只能新增 run 或在报告中注明修订原因。
9. exp004 已完成覆盖与累计保护诊断：覆盖扩大是一个有方向性证据的解释，但线性累计保护被真实 logprob 轨迹否定；不启动多 seed，也不在同一实验卡内继续增加线性投影规则。任何轨迹感知保护方法必须另建实验卡并冻结新的直接 logprob 指标。
10. exp005 已完成实际 logprob 反馈补强：反馈相对 raw AdamW 有效，但相对 COV16 的最终下降率只改善 1.54 个百分点，retain 为 19/33，未达到 20/33 推进门；不启动多 seed，也不在本卡内继续搜索阈值、轮数或预算。
