## 1. 一句话概括

针对"模型忘掉了目标事实、但能通过保留知识多跳推理把目标重构出来"的问题，提出 **DUMIC**（Deep Unlearning via Minimum Inferential Cuts）：先把模型内部支撑目标事实的推理路径挖出来，再用**置信度加权的最小割**选出最小代价的切断集，连同目标一起遗忘。框架可套在任何现有遗忘算法（GA/NPO/SimNPO/GDR 系）之上。

## 2. 问题形式化（§3，本文数学核心）

- 模型知识 = 置信度图 $G^{M_{pre}} = (E, R, T^U)$，事实 $t=(s,r,o,u)$，$u$ 为**温度缩放校准后**的置信度。
- 支撑路径 $P_i=(t_{i,1},\dots,t_{i,\ell_i})$：一条能推理出目标 $e$ 的事实链。
- 路径置信度取**最弱环节**：$C^A(P)=\min_{t\in P} u_A(t)$（与"链条强度由最弱环决定"一致）。
- **深度遗忘判据**：方法 $A$ 在阈值 $\gamma$ 下达成深度遗忘 ⟺
  $u_A(e)\le\gamma$ 且 $\forall P\in Q_e:\ C^A(P)\le\gamma$。
  - $Q_e=\varnothing$ 时退化为浅层遗忘（只压目标本身）；
  - $Q_e=\mathcal{P}^{M_{pre}}(e)$ 时为完全深度遗忘（所有已验证路径都要断）。
- **割的定义**：事实集 $C$ 是割 ⟺ $\forall P\in Q_e,\ C\cap P\neq\varnothing$（每条路径至少砍掉一个事实）。

## 3. 方法三阶段（§4）

### 3.1 Search — 自适应树搜索（发现候选路径）
- 从 $s^*$ 出发做 BFS，搜索节点 $n=(v,\pi)$ 存当前实体 + 已走路径，逐层扩展直到到达 $o^*$（有最大深度限制）。
- **显式 + 隐式双通道实体发现**：
  - 显式：问模型 "How is v related to ...?"，从回答中抽实体；
  - 隐式：**J-Lens（Jacobian lens）** 从中间层表示中解码出"回答里没说但内部编码了"的实体——概率阈值 $10^{-4}$ 降噪、按 readout 概率排序、每字段保留最多 3 个新实体、显式实体优先。
- **关系边验证**：候选实体 $w$ 必须再向模型查询确认 $(v,r,w)$ 存在才扩展（出现 ≠ 有关系）。
- 最后一跳直接验证 $(v,r,o^*)$，跳过后继候选生成（省一个分支因子）。
- 效果：J-Lens 使发现路径数 Gemma 1018→2632（2.59×）、Qwen 2407→3343（1.39×）；过滤后目标覆盖率 76%→93%、91%→96%。**表面回答会漏掉关键推理路线，中间层表示能补出来。**
- 效率：vLLM 批量推理，平均每目标 80.2s（Qwen-27B）/ 157.9s（Gemma-31B）。

### 3.2 Select — 路径剪枝 + 置信度过滤（构建支撑子图 $G_e$）
- LLM judge 判断"这条路径上的关系联合起来是否支撑目标 $e$"（只允许用给定事实，判不支撑就丢）。
- 幸存路径的三元组取并集 = 支撑子图。
- 每个三元组转成 **A/B/C/D/Unknown 五选 MCQA**，做**温度缩放校准**（Qwen 拟合温度 1.6，ECE 0.144→0.062；Gemma 1.3，0.077→0.075），答案正确且校准置信度达标才保留。
- 附录 E 给出熵阈值与正确率的换算表（五选项下 $H(q)<u^*$ 对应的正确概率区间）。

### 3.3 Sever — 置信度感知最小割（选遗忘集）
- 割集 $C$ 命中所有路径；每条事实的**切断权重 = 它自己的置信度** $c(t)=u$（置信度越高 = 模型越确信 = 删掉代价越大，倾向保留）。
- 选总权重最小的割：$C_e^* \in \arg\min_{C\in K_e} \sum_{t\in C} c(t)$，与目标 $e$ 合并成最终遗忘集。
- 直觉：用最小代价打断所有恢复路径，而不是无脑忘掉整个支撑子图。

## 4. 实验（§5–6，附录 A–F）

**设置**：Harry Potter 七本书建参考 KG（1,862 实体 / 4,122 三元组；GPT-5 + Gemini 3.1 Pro 抽取、别名合并、补全、二次审查）；选验证路径数最多的 100 个三元组当目标；模型 Qwen3.5-27B 与 Gemma4-31B-Base；5 个遗忘方法（GA / NPO / SimNPO / GA_GDR / NPO_GDR）× 3 种设置（Superficial / DeepUnlearn / DUMIC）；全参 lr 5e-6、LoRA lr 1e-5；epoch 选择用 utility>0.8 的最后一个 epoch。
**指标**：UES（路径置信度归一化下降，路径断=1）、Loc（目标三跳邻域 30 条事实前后预测一致率，排除支撑子图）、Gen（MMLU）、Rea（BBH）。

**三个主发现**：
1. **DeepUnlearn 忘得更深但会塌**：Gemma 上 GA/NPO 的 Loc 和 Rea 直接掉到 0；Qwen 上 UES 全部 >0.93。
2. **最小割在深忘与效用之间找回平衡**：Gemma 上 GA 的 Loc 从 0 恢复到 0.905、Rea 到 0.698，UES 仍比浅层高 +25%；NPO_GDR Loc 0.196→0.844。UES 相对浅层提升 11.6%–358.9%。
3. **LoRA 下同样有效**（Table 2）：GA 0.109→0.789（+623%），GA_GDR −0.643→0.548；说明框架不限于全参微调。

**消融**：epoch 前两三个涨完就饱和、继续训只掉效用；目标数 50→200 时 UES 0.99→0.73（新增目标路径覆盖率低）；**控制遗忘集大小**（把浅层集也扩到 236 条）：DUMIC UES 仍全面更高（+0.033~0.167），证明增益来自"选哪些事实"而非"多喂数据"。

## 5. 对本研究（蓝恩鹏）的直接映射

| DUMIC | 本研究对应物 | 关系 |
|---|---|---|
| 支撑路径/恢复路径 | hop2 多跳恢复、F1_hop2 | **同一问题**：忘目标 ≠ 断推理链 |
| 贪心拓展遗忘集（G2） | 最小割选遗忘集 | **同方向、不同选法**：贪心按"紧邻 F0"扩；min-cut 是"以置信度为代价命中所有路径"的优化形式，理论更干净，且自带代价感 |
| 路径置信度 = min(事实置信度) | D_hop2 集全链路封堵判据 | 一致的"最弱环节"聚合逻辑 |
| J-Lens 隐式实体发现 | 内生源知识图谱（fig12）/ 贪心挖掘 | 互补：他们做**逐目标搜索**，我们做**全图构建**；其结论"表面回答漏路径"支持内生源 KG 的必要性 |
| A/B/C/D/Unknown 五选 + 校准置信度 | 本工作 MCQA 评测协议 | **几乎同一评测形态**，可直接借鉴其 ECE 校准与熵阈值口径 |
| UES（路径级） | 多跳封堵率（hop2/D_hop2） | UES 更细（连续置信度 + 断路径二值），可引入作为补充指标 |
| SimNPO 在小预算 LoRA 下 UES≈0.08/为负 | 本工作 11-baseline 中 SimNPO/RMU 等"未有效遗忘" | **独立互证**：27B 全参 vs 1.5B LoRA 都出现，说明是方法结构问题而非规模问题 |
| 框架套在 5 种遗忘算法上 | GSU 梯度手术 | 潜在组合：把 GSU 当作 DUMIC 框架内的遗忘算子，或把 min-cut 选集接到 GSU 前面替换贪心拓展 |

**关键差异**：他们用 27–31B 全参 + GPT-5/Gemini 当 judge 和建图器（外部强模型依赖重、有循环性疑虑），虚构域单一，评估基于参考 KG 上的固定 MCQA（非开放生成攻击）；我们用 1.5B LoRA 自包含闭环。

## 6. 局限与可质疑点（写相关工作/审稿角度可用）

1. 参考 KG 与 judge 都靠 GPT-5/Gemini，"用 LLM 评 LLM 遗忘"有外部依赖与标注偏置；
2. UES 在参考 KG 的固定路径上算，未测自由生成/对抗提示下的真实重构攻击；
3. 单域（Harry Potter）、100 目标，规模有限；
4. 路径置信度取 min 是启发式，无理论最优性；
5. 最小割求在"已发现子图"上最优，覆盖不足时（200 目标 UES 下降）无内建机制；
6. 未与"拓展遗忘集"类贪心选集做直接对照（只与全子图、只忘目标比）——**这正是我们 G2 实验能补的空白**。

## 7. 可立即借鉴的三件事

1. **UES 指标口径**：路径置信度归一化下降 + 断路径二值分，比单一封堵率信息量更大，可加入本工作评测台；
2. **min-cut 选集对照组**：在我们的坐标系里加一个"拓展遗忘集 = 支撑子图最小割"的 G2 变体，直接回应"贪心 vs 优化选集"；
3. **温度缩放校准**：给 1.5B 模型的 MCQA 置信度做 ECE 校准（附录 E 有现成的五选项熵-概率换算表），让 K 集/retain 的置信度报告更可信。
