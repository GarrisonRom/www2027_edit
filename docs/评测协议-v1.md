# FaithUn 评测协议 v1

> 冻结日期：2026-10-17　整理日期：2026-10-19
>
> 该文件记录已经用于 1.5B 主线和 3B clean 扩展的评测口径。后续新增实验不得静默改变模型、数据、split、提示、指标或随机性；若必须改变，应新建协议版本。

## 1. 数据与模型

- 数据：`data/faithun/FaithUn_Dataset.json`
- 数据 SHA-256：`D570CC3E30C083357CA45AB4DD9DF807ABBD800F51A657D89629E4FE7B3ADBB0`
- 数据规模：200 个实体、664 个事实簇；forget 33、retaining 66、test 464，三者互不重叠。
- 1.5B：由 `QWEN_1_5B_PATH` 指定本地模型目录
- 3B：由运行命令的 `--model` 参数指定本地模型目录
- 推理环境：Python 3.10.18、PyTorch 2.6.0+cu126、Transformers 5.14.1、PEFT 0.20.0、CUDA 12.6。
- 默认推理：本地离线加载、bf16、无 chat template；显存受限时使用 `sdpa` 或 `eager`，不得切换成不同对话模板后混报结果。

## 2. 问题与打分

1. 每题使用正确答案和数据集给定的两个干扰项构成三选一 MCQA。
2. 对每个候选答案计算续写的长度归一化 log probability，取 argmax 作为预测答案。
3. `hop1_unlearn` 作为初始遗忘事实；`hop1_test`、`hop2_test`、`hop3_test` 和 `same_object` 作为评测或分析数据。
4. hop1 一致率使用 `hop1_unlearn` 原问和 3 个 `hop1_test` 改写；四次 argmax 命中率为事实掌握度。
5. hop2 子项包含 3 个改写，至少 2 个改写答对才计为该子项正确；原始模型在该子项答对时记为活跃路径。
6. 主要指标是 MCQA 正确率；正确率越低表示遗忘或恢复风险越低，retain、same_object 和 K 集则越高越好。logprob 只作为辅助指标。

## 3. 研究内容一分组

| 组 | 遗忘对象 | 说明 |
|---|---|---|
| orig | 无 | 原始模型 |
| G1 | F0 | 只遗忘 33 个种子事实 |
| G2 | F0 + 贪心 F1 | 主组，F1 为预算 B=5 的探测驱动扩展事实 |
| G3 | F0 + 全部候选 | 不筛选扩展的对照 |
| G4 | F0 + 随机 5 | 等规模随机对照 |
| G5 | F1 | 只遗忘扩展事实，用于路径依赖消融 |

1. 1.5B 使用 `eval_results_1p5B_v2.json`；3B 最终使用 `eval_results_3B_v2_clean.json`。
2. 1.5B 主实验本轮未启用公共知识撤回禁区 `R`；涉及 `R` 的结果必须标记为后续版本。
3. 3B 使用独立候选探测和每组独立冻结基座；`3B_v1` 因 PEFT 重复适配器警告不作为最终数字。

## 4. 研究内容二协议

- 模型对：原始模型 M 与 G1/G2 遗忘模型 M' 分开比较，不混合 G1/G2 的归因矩阵。
- 损伤分：`d(f) = log p_M(a|q) - log p_M'(a|q)`。
- D 组：`same_object` 和 `hop2` 按 G2 的 d(f) 各取 top-24；K 组为同来源最低损伤题，合计 48 题，源内匹配。
- 组件干预：权重撤销替换回原始模型 M；报告定向层、随机层、神经元和模块分解结果。
- 预测验证：用阶段 2 的逐层显影分数预测阶段 3 未参与排序的 28 层单层 MLP 撤销收益；G1→G2 是跨遗忘模型对留出，不是跨架构泛化。

## 5. 研究内容三协议

- 起点：1.5B G2 adapter。
- 监督：来自损伤表的合法保留题；与遗忘答案共享 token 的题不直接进入恢复监督。
- 六个评测集：`D_so`、`D_hop2`、`hop1_unlearn`、`F1_hop2`、`K`、`retain`。
- 相对指标：恢复率和回弹率均以 `orig - G2` 的可恢复空间归一化；K 漂移必须同时注明是 logprob 还是 MCQA 口径。
- 预先冻结硬门槛：恢复率至少 30%，F0 回弹不超过 10%，F1 复活不超过 5%，K 漂移不超过 5%。
- R5 的 MCQA 与 logprob 结果必须分开报告，不能用 logprob 恢复替代行为恢复。

## 6. 随机性与归档

- 3B probe/select/train 的 seed 为 42；训练脚本还存在 Python hash-based retain sampling，复现实验必须显式固定 hash 或记录其状态。
- 1.5B 历史实验的结果文件已保存，但未为每次运行单独建立机器级 run log；论文引用时使用结果文件，并在证据总账中标记该缺口。
- 3B run 目录：`exp/runs/exp001_3B_extension/`。
- 原始数据、模型权重、适配器和已有 JSON/JSONL 不覆盖；协议变更使用新文件名和新 run 目录。
