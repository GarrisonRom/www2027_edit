## 估测的科学边界

无法从本地1.5B的A/B端点可靠推算新架构C2的成绩。本报告不伪造预计正确率、
概率或方法排名。候选C2是当前模型梯度/路径风险+真实F1方向子空间+实际位移路由
+F0进展护栏，已在exp011完成单种子先导，尚无优于GA的主要计数证据。

可以定义一个有依据的目标区域：相对当前GradDiff固定配置，F0正确数不增加、
覆盖多跳正确数至少少1题、非锚点正确数不下降。Qwen为<=12/33、<=45/75、>=16/33；
Llama为<=14/33、<=62/75、>=22/33。这是事后设计目标而非预测，不替代新卡冻结，
不代表已知全部hop2、生成行为或低关联能力上的优越性，也不声称支配所有baseline。
