## 6. 损伤现场根因分析：KL 锚为什么失效

三个证据（数据核验，排除实现错误）：

* **全分布均匀下压**：576 题 d\_G2 无一为负（最小 0.10），梯度上升对所有题的答案概率都有向下推力，KL 锚只部分抵消；

* **共享 token 是结构性损伤源**：same\_object 与 $F_1$ 扩展事实共享答案 token，遗忘梯度直接打在共享 token 上，通用分布锚原理上护不住；

* **崩溃与扩展无关**：G1（只忘 $F_0$）retain 同样 0.76→0.39——是"梯度上升 + 弱锚"的通病，不是 G2 的扩展遗忘集引入。

配置层面：原始 G2 每步仅锚 1 条随机 retain 样本、$\alpha=10$ 为两损失量级间的经验取值；但 G6 将锚样本增至 4 条、$\alpha=30$ 后仍然更差，说明“约束强度不足”不是完整解释。

**对论文的收敛**：内容一成功判据只声称 hop2 封堵（H2 成立），不声称"KL 保护保持集"；"KL 锚在共享 token 场景下失效"本身作为定量结论写入。内容二的存在理由因此更充分。

## 7. 锚强度对照组 G6：分布级 KL 锚存在结构性盲区（否定性结果，价值重大）

**设计**：G6 = G2 同款遗忘集（$F_0$ + $F_1$ 贪心5 = 38 条），KL 锚加强为每步 4 条保持样本、$\alpha=30$（锚强度约 ×12），其余超参与 v2 一致。训练日志：末轮 forget=−22.69（遗忘更彻底）、kl=0.079（锚约束本身被执行得很好）。

**实测五指标**（vs G2 / G1 / orig）：

| 组      | hop1\_unlearn | hop1\_test | hop2      | same\_object | retain    |
| ------ | ------------- | ---------- | --------- | ------------ | --------- |
| orig   | 0.636         | 0.646      | 0.644     | 0.757        | 0.758     |
| G1     | 0.182         | 0.202      | 0.363     | 0.319        | 0.394     |
| G2     | 0.182         | 0.192      | 0.255     | 0.257        | 0.394     |
| **G6** | **0.121**     | **0.121**  | **0.255** | **0.160**    | **0.333** |

**回答"锚加强后 retain 能否守住"：不能，反而更糟。**

1. retain 准确率 0.394 → 0.333，same\_object 0.257 → 0.160——锚强 12 倍，保护集掉分反而更多；
2. retain 对数概率均值损伤 d 从 4.28 降到 2.84（面上更轻）但翻转更多——G6 的损伤更"结构化"：专打排名边缘的题，广谱压低少了、精准翻转多了；
3. hop2 封堵 0.255 与 G2 完全相同（多跳恢复已到地板），hop1 遗忘更深（0.121 < 0.182）；
4. 训练全程 KL 被压在 0.08 附近——**锚被忠实地执行了，但保护照样崩**。

**结论**：连带损伤不是"锚不够强"的问题。分布级 KL 锚只约束被锚序列的输出分布，对共享答案 token 的梯度下压是结构性盲区：模型可以在保持锚样本 KL 很小的同时，把语义相邻题的答案排名做掉。这一否定性结果排除了"调大 α 就行"的最自然质疑，直接论证了内容三**组件级、目标级修复**（而不是更强的全局锚）的必要性。数据存 `exp/results/g6_anchor_summary.json`，adapter 在 `exp/adapters/1p5B_v2_G6/`。

### 7.1 机制分析：为什么更强的锚反而伤得更准

**（1）锚的数学覆盖域太小。** KL 锚只约束每步被抽中的 4 条序列的输出分布：全程 114 步 × 4 条 ≈ 456 条序列约束（含重复），而 same\_object 的改写空间无界（评测里就有 144 道）。共享答案 token 的题恰恰落在覆盖域之外——它们的 logits 被遗忘梯度直接推动，而没有任何一项损失把它们推回去。

**（2）AdamW 的均衡机制决定锚只能改方向、不能限总量。** 总损失 $\mathcal{L}=\ell_f + 30\cdot\mathrm{KL}$ 在末态取得 forget=−22.7、KL=0.078，即模型在 LoRA 子空间里把遗忘推得更远（hop1 0.182→0.121 证明移动总量确实更大）。自适应优化器对梯度幅值归一化，α 改变的是梯度场的**方向配比**：只要 $\partial\ell_f/\partial\theta$ 存在与锚梯度近正交的分量（低秩 LoRA 里这样的分量必然存在），遗忘就会持续进行，损伤被路由到锚监控不到的序列上。

**（3）"广谱损伤减少、精准翻转增多"是盲区的指纹。** G6 的 retain 对数概率均值损伤更小（2.84 < 4.28）但准确率更差——与遗忘集**无共享 token** 的题被锚保护住了（d 小），与遗忘集**共享 token** 的题被精准做掉排名（翻转）。这给出论文可用的可检验预测：**G6 的损伤应更集中在共享 token 题子集上**（可在阶段 3 顺手验证）。

**（4）hop2 封堵持平的解释。** 多跳恢复要求 $F_0$、$F_1$ 同时存活；G6 把 $F_0$ 忘得更狠（hop1 0.121），hop2 只能在同一地板（0.255）上持平——封堵效果对锚强度完全不敏感，因为瓶颈在 $F_0$ 存活率。

## 8. 阶段 3：组件撤销因果实验（图 D3）

**协议**：在 G2 merge 后的全权重模型上手术替换——层撤销 = 该层 gate/up/down\_proj 整体换回 M；神经元撤销 = 该中间神经元的 gate/up 第 i 行 + down\_proj 第 i 列换回 M。评测集含受损集 D（48）、对照 K（48）、遗忘判据 hop1\_unlearn（33）、F1 复活判据 F1\_hop2（75）。16 个配置，数据存 `attribution/ablation_G2.jsonl`。

### 8.1 核心数字（恢复率 = 占 orig−G2 可恢复空间的百分比）

| 配置              | D 恢复%    | $F_0$ 回弹% | $F_1$ 复活% | K 漂移% |
| --------------- | -------- | --------- | --------- | ----- |
| 层 27 MLP        | 9.6      | 8.3       | 7.7       | 5.2   |
| **层 22–27 MLP** | **34.4** | 30.3      | 31.9      | 22.1  |
| 随机 6 层 MLP      | 13.8     | 12.4      | 11.3      | 16.2  |
| top-12 神经元      | 3.8      | 3.1       | 2.7       | 4.5   |
| 随机 12 神经元       | 3.6      | 3.0       | 2.5       | 4.3   |

### 8.2 三个结论

1. **层定位有因果效度**：定向撤销层 22–27 的恢复率（34.4%）是随机 6 层（13.8%）的 **2.5 倍**——阶段 2 的 FFN 层定位携带真实因果信号，不是相关性巧合。
2. **神经元定位不可操作**：top-12 与随机 12 神经元的恢复率无差别（3.8% vs 3.6%），top-k 曲线（k=1→12）全程 < 2%。**层内损伤是分布式的**——阶段 2 找到的是"漂移最大的神经元"，不是"功能的居所"。这对内容三是直接的方法学指导：**修复粒度应取层/模块级，稀疏神经元手术无效**。
3. **恢复与回弹同源（剪刀差）**：撤销 6 层换回 34% 损伤的同时，$F_0$ 遗忘回弹 30%、$F_1$ 复活 32%——损伤与遗忘记忆**共存于同一批组件**，不存在"只修损伤不动遗忘"的免费午餐。权衡图（图 D3 右）显示层 27 单独撤销是恢复/回弹比最优点（9.6%/8.3%），恢复量有限。

### 8.3 模块分解实验：核心原因的直接定位（受控实验）

**问题**：层 22–27 只恢复 34%，上限是什么？**假设**：损伤分散存储在 LoRA 触及的两类矩阵（注意力 q/k/v/o、MLP gate/up/down）里。**实验**：分别在 merge 后的 G2 上换回各类矩阵，全层与 22–27 层两档。附带 `undo_all` 全流程校验（恢复结果与 orig 逐位一致，差 < 0.001，协议本身无误）。

| 撤销配置            | D 恢复%    | $F_0$ 回弹% | 结论                             |
| --------------- | -------- | --------- | ------------------------------ |
| 层 22–27 MLP     | 34.3     | 30.3      | 原方案                            |
| 层 22–27 注意力     | 9.0      | 7.8       | 注意力承载少                         |
| 层 22–27 两者      | 43.6     | 39.4      | 叠加近似可加                         |
| **全部 28 层注意力**  | 17.4     | 16.4      | 独立撤销收益占可恢复空间约 17%，**无层特异性**（6 层≈全层一半） |
| **全部 28 层 MLP** | **88.7** | 87.2      | 独立撤销收益占可恢复空间约 89%            |
| 全部两者（=orig）     | 100.0    | 100.0     | 校验通过                           |

**核心原因（回答"为什么不如预期"）**：

1. **MLP 撤销可恢复约 88.7% 的可恢复空间，但收益不能与注意力撤销率简单相加**；MLP 损伤信号近乎均匀地分布在全部 28 层（每层约 3.2%；随机 6 层期望约 19%，实测 14%）。阶段 2 定位的层 22–27 是“漂移最大”的层，但只承载约 1/3 的撤销收益，稀疏层假设被证伪；
2. **注意力矩阵独立撤销收益约 17% 且各层均匀**——这解释了头归因的 null 结果：在本协议下，主要损伤信号走 MLP 通路，注意力不是高回报恢复对象；
3. **层内分布式 + 层间近均匀 = 神经元手术必然无效**（12/250k 参数翻不出浪花），阶段 3 的神经元 null 结果与模块分解自洽。

### 8.4 共享 token 机制分析（解释 same\_object 全面崩溃与低层分离）

D/K 答案与遗忘集答案的重叠统计：

| 组               | 答案恰为遗忘答案    | 说明                                              |
| --------------- | ----------- | ----------------------------------------------- |
| D\_same\_object | 24/24（100%） | same\_object 答案与 $F_0$ **完全共享**（题目即"同一对象的其他问法"） |
| K\_same\_object | 24/24（100%） | 共享但损伤轻 → 崩溃与否取决于压得多狠，不是是否共享                     |
| D\_hop2         | 21/24（88%）  | 被压的 hop2 子项答案就是 $F_0$/$F_1$ 答案本身                |
| K\_hop2         | 0/24（0%）    | 未受压子项与遗忘集无共享                                    |

机制闭环：遗忘梯度打在答案 token 上 → 凡答案 token 与遗忘集共享的题一律受压（same\_object 100% 共享 → 全面崩溃）→ 受压序列在低层的 token 身份编码首先漂移（解释图 D2 的低层分离带）→ 损伤经 MLP 分布式存储（解释模块分解）。

### 8.5 对内容三的直接输出（修订版）

* **修复单元（修订）**：**MLP 全域为恢复对象**（承载 89% 损伤），层 22–27 仅作优先加权而非唯一目标；注意力无需处理（承载 17% 且均匀，投入产出差）；神经元级手术正式排除；

* **收益预测基准（修订）**：组件撤销范式全量恢复 ≈89% 损伤但伴随 ≈87% 遗忘回弹——**"撤销"范式整体走到头**，恢复与遗忘同源，不存在稀疏组件级的无损修复；

* **内容三路线定论（数据支持）**：必须超越组件撤销，采用**定向恢复微调**（以受损事实为监督、以 LoRA 为更新载体、以零空间/遗忘保持约束限回弹）——这正是内容三的原设计，现在有了"为什么必须如此"的实验证据链：G6（全局锚无效）+ 模块分解（损伤分布式存储）+ 剪刀差（恢复与遗忘同源）三重论证；

* **遗留的理论价值**：损伤"模块集中（MLP）、层内分布式、层间近均匀"的存储结构，与表征工程中"MLP 存知识、注意力算路由"的共识一致，可作为内容二讨论章节的分析素材。

## 9. 阶段 3 小结

组件撤销因果链闭合：定向层撤销恢复 34.4%（随机 13.8%，2.5×）证明归因有因果效度；模块分解进一步定位核心原因——**损伤 ≈89% 存储于 MLP 且层间近均匀**，34% 上限是损伤真实存储结构的反映；恢复-回弹剪刀差（6 层撤回 = 30% $F_0$ 回弹 + 32% $F_1$ 复活）宣告组件撤销范式走到头，内容三必须走定向恢复微调路线。

## 10. 阶段 4：可检验预测——内容二的存在证明（图 D4）

**实验设计**：预测对象为**全层单层撤销扫描**（28 层 × 各自单独换回 M 的 MLP，阶段 3 未做过的干预，模型单次加载 + 层权重缓存往返，一次跑完）。显影得分为阶段 2 的逐层 FFN 漂移（受损组 D），并做**跨遗忘模型对留出检验**（用 G1 的显影得分预测 G2 的实测收益；底座架构不变）。随机基线为 1000 次随机打分的 |ρ| 分布。

**结果**：

| 显影得分来源               | Spearman ρ | p        | 判定   |
| -------------------- | ---------- | -------- | ---- |
| G2 自身 FFN 漂移         | 0.824      | 7.0×10⁻⁸ | ✅    |
| **G1 FFN 漂移（跨遗忘模型对留出）** | **0.830**  | 4.8×10⁻⁸ | ✅ 留出 |
| G2 隐状态漂移             | 0.842      | 2.0×10⁻⁸ | ✅    |
| 随机基线（\|ρ\| 均值）       | 0.152      | —        | 对照   |

**内容二成立**：显影得分对未做过的撤销收益具有强预测力（ρ≈0.83，为随机基线的 5.4 倍），且在**不同遗忘模型对之间留出**（G1→G2）不降级——归因不是对单一模型对内部排序的直接复述，而是当前底座架构与协议下可迁移的损伤度量。显影管线从"描述性分析"升格为**内容三恢复阶段的选址器**，正面回应盲审 Major 意见。
