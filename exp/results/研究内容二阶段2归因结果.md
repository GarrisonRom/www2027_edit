# 研究内容二 · 阶段2 归因结果报告（2026-10-17）

> 模型：Qwen2.5-1.5B-Instruct + GA-LoRA 遗忘适配器（G1 只忘 $F_0$ / G2 $F_0$+$F_1$ 贪心5）
> 输入：`attribution/items.json`（D 受损组 = same_object top-24 + hop2 top-24 按 d_G2；K 对照组 = 同来源 d_G2 最低 48 题，源内匹配）
> 代码：`exp/damage/attribution.py`（四 part 可断点续跑）、`exp/damage/plot_stage2.py`
> 统计：逐层配对 t 检验（D vs K，48 题），`attribution/stats_stage2.json`

## 1. 层间激活漂移（图 D2 / fig14）

末 token 隐状态 M vs M′ 余弦漂移 $1-\cos$，逐层曲线：

- **G2**：D 与 K 的显著分离只出现在**低层（层 1–4，p<0.01，t 峰值在层 2 = 6.73）**；中高层 K 漂移反超 D（末 5 层均值差 −0.0029）。
- **G1**：分离带在**层 5–13 + 层 25**（t 峰值层 8 = 4.27），同样末层 K > D。
- G2 整体漂移幅度约为 G1 的两倍（末层 0.033 vs 0.016），与"G2 训练样本更多、KL 锚约束下的参数移动更大"一致。

**解读**：受损事实的"指纹"不在末层而在**低中层**——高层漂移是所有题共有的（KL 训练对全分布的推移），用高层漂移做损伤定位会被背景噪声淹没。这修正了规划中的预期（"中高层漂移更大"）。

## 2. 注意力头归因（图 D2b / fig15）：null 结果

28 层 × 12 头热力图（受损−对照，末 token 对前文平均注意力差）：

- G2 mean|diff| = 0.02064，max = 0.02069；G1 mean = 0.02064，max = 0.02069。
- **跨头几乎完全均匀，无任何局部头突出**；两组的最大头位置不同（G2: L24H8，G1: L3H0），属噪声。

**结论**：在本口径下注意力头不是损伤的承载组件。这是一个**可写进论文的否定性结果**——与 UNPACT（注意力扰动解释遗忘）形成对照：GA-LoRA 型遗忘的损伤不体现在注意力重分配上。

## 3. FFN 神经元归因（图 D2c / fig16）：最强信号

FFN 中间激活（down_proj 输入）|M−M′| 逐层均值：

- 漂移随层数单调上升，**峰值在末层（层 27）**：G2 D 组 0.133，G1 D 组 0.094；G2 > G1 ≈ 与训练强度一致。
- **top-20 神经元（按 D−K 差排序）G1/G2 交集 12 个，全部集中在层 22–27**：
  (22,7602) (24,2584) (25,3791) (25,4105) (25,7610) (26,1153) (26,6363)
  (27,5431) (27,5845) (27,7551) (27,7926) (27,8173)
- G2 全局 top5：L27N7926 (4.09)、L25N4105 (3.57)、L27N5431 (2.52)、L26N1153 (2.48)、L27N7551 (1.87)。
- 同一个神经元在两组间排序一致（如 L27N7926：G1 3.30 / G2 4.09），说明这些组件承载的是**两组共享的损伤通路**，G2 只是动得更狠。

**组件清单已冻结**（`attribution/ffn_{G1,G2}.json` topk，每层的全局 top-20），作为阶段 3 组件撤销实验的候选目标。

## 4. 梯度归因对照（图 D2d / fig17）

冻结原模型 M 上答案 NLL 的逐层梯度平方和（Fisher 代理）：

- D 与 K 的梯度剖面形状几乎一致（层 1 尖峰 + 层 18 次峰 + 层 27 回升），两组峰值层相同（层 1）。
- **行为层损伤分 d(f) 不对应参数层敏感度**——高损伤题并不落在高梯度区。这意味着 Fisher 型选点（TRIAGE 路线）对"已被遗忘训练伤到的题"没有区分力，损伤定位要靠激活漂移（第 1 节）而非梯度（此即阶段 1.2  Fisher 对照的预判，可合并到该节做正式验证）。
