# Strengthen probe 01：实际 logprob 反馈与有限修正预算

## 断链定位

当前链条是：遗忘梯度产生 AdamW proposal → retain 锚点的一阶投影修正 proposal → retain 代理指标改善 → 最终 retain 保持。exp002/003/004 已把断点缩小到“局部一阶代理到真实多步 logprob 的转移”：

- M3U 的聚合约束改善同批平均 logprob，但逐锚点仍有冲突（`run_20261020_1115_m3u_diagnostic_rerun`）。
- M3A 将每个锚点纳入约束后，直接锚点 logprob 在 `439/456` 个配对观察中改善，但 retain 只有 `11/33`（`run_20261020_1332_m3a_train_diagnostic`）。
- COV16 将每步覆盖扩大到 16 个锚点，覆盖了 `33/33` 个 retain 身份，最终 retain 为 `20/33`，但修正前后仍有 `866/1824` 个直接 logprob 观察下降，且实际写回残差有 `9/1824` 超过 `1e-5`（`run_20261020_cov16_rerun`）。
- CUM16 的线性累计下限在求解器层面成立，但固定锚点的真实累计 logprob 最差下降 `25.5761`（`run_20261020_cum16`）。

因此目前最具体的断点不是锚点覆盖，也不是约束求解器，而是修正后没有重新询问真实 logprob，导致一阶预测误差被跨步累积。

## 候选方法

GSU-v5-actual-feedback 保留 COV16 的每步 16 个新采样锚点和原始遗忘梯度 → AdamW proposal。AdamW 写回后直接计算这 16 个锚点的实际答案 logprob；仅对实际下降超过固定容差 `1e-4` 的风险锚点计算当前状态梯度，求最小范数的补偿位移。补偿后重新评估实际 logprob，最多再反馈一次。每步累计补偿位移限制为原始 AdamW 位移范数的 `0.30` 倍。

`0.30` 来自 COV16 修正位移比例的 90 分位 `0.285745`，向上取整到可复现的固定预算；它允许覆盖 COV16 的典型修正，同时排除 CUM16 的极端比例（最大 `2.177987`）。`1e-4` 是 exp004 实际残差门 `1e-5` 的十倍，用来避免把数值噪声当成风险。反馈轮数和预算在跑实验前冻结，不按最终结果调节。

## 可判别预测

如果“真实 logprob 反馈”是断点的关键，FB16 相对 COV16 应同时出现：

1. 直接锚点最终 logprob 下降比例降低，尤其是 COV16 仍下降的 `866/1824` 个观察应减少；
2. 实际反馈后的风险锚点数随轮次下降，且每步修正比例始终不超过 `0.30`；
3. 最终 retain 不低于 COV16 的 `20/33`，而 F1_hop2 不高于 COV16 的 `29/75`，说明保护收益没有靠完全停止遗忘获得；
4. 如果最终 retain 没有提高，或只靠超过预算的修正才能提高，则说明真实 logprob 反馈本身不是充分机制，候选停止。

保守解释的判别是：如果 FB16 的实际下降率、最终 retain 和 F1_hop2 都与 COV16 没有方向性差异，且风险锚点主要在反馈后仍然存在，则 exp004 的覆盖改善可能只是一次性 seed 波动。

## 预算与 kill rule

- 1 个固定 seed（42）、同一 Qwen2.5-1.5B、同一 G2 遗忘集、同一 33 条 retain、3 epochs/114 更新；不搜索学习率、锚点数、反馈阈值、反馈轮数或预算。
- 每步最多 2 个反馈轮次；总补偿位移相对 raw AdamW 位移上限为 `0.30`；AdamW 动量不因补偿回写。
- 若出现非有限值、反馈求解器不收敛、实际修正比例超过预算、更新数不足 114 或评测样本数异常，run 记为 failed 并停止推进。
- 即使 sanity 通过，若最终 retain `<20/33`、F1_hop2 `>29/75`、主指标 `<3/12`，或直接 logprob 下降率没有比 COV16 至少下降 10 个百分点，则不进入多 seed，候选判为 reject/redirect。

## 后续

结果只用于判断这条实际轨迹反馈机制是否值得进入新的多 seed 卡。无论结果如何，exp002–exp004 的原始 run 和指标不覆盖。
